# 🌐 Responsive Landing Page

A clean and fully responsive landing page built with **HTML5** and **CSS3**, featuring a modern navigation header, a hero section with a clear call-to-action, and a simple footer with social links.

## ✨ Features

- 📱 **Responsive Design** — Seamlessly adapts to desktops, tablets, and mobile devices.  
- 🧭 **Navigation Bar** — Easy-to-use navigation with Home, Features, and Contact links.  
- 🚀 **Hero Section** — Eye-catching heading, supporting text, and a prominent CTA button.  
- 🔗 **Social Links** — Placeholder icons for LinkedIn, Twitter, and Facebook.  
- 🎨 **Clean UI** — Minimal, elegant, and easy-to-customize layout.  
- ⚡ **Lightweight** — Built using only HTML and CSS, no external frameworks.  


## 🛠️ Technologies Used

- **HTML5** — Semantic structure and accessibility.  
- **CSS3** — Styling, layout, responsiveness, and visual design.
